# What2Craft

What2Craft helps you find profitable items to craft and sell in FFXIV using market data from Universalis and recipe data from XIVAPI.

**[Visit What2Craft](https://mikeguylol.github.io/What2Craft/)**

Compare estimated crafting profit, material costs, and sales activity across North American worlds. Data refreshes daily.

Prices and sales figures are estimates, not guaranteed profits. Check current listings before buying materials.

Powered by [Universalis](https://universalis.app/) and [XIVAPI](https://xivapi.com/). If you find this useful, please consider supporting Universalis!
